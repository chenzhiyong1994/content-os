# 小红书图片生成

## 先读

- `docs/operations/workflow-rules.md`
- `skills/xiaohongshu-adapt/SKILL.md`

## 核心职责

读取 `06_小红书版` 中的漫画分镜部分，并在独立阶段生成图片资产。

本 skill 负责：

1. 解析分镜 markdown
2. 先生成角色图
3. 用角色图作为分镜图参考
4. 整理本地图片资产，方便审看

本节点不改写分镜内容，也不读取同一个 `06_小红书版` 文件中位于漫画分镜前的小红书发布正文。

## 确认点

这是完整流程的默认下游阶段，但执行付费生图前必须暂停并获得用户明确确认。

生图前展示：

- 文章标题
- 角色图数量
- 分镜图数量
- 唯一活动生图路径
- 模型、尺寸和计划输出路径
- 当前准备生成的角色图或分镜图完整 prompt

没有用户明确确认，停在 `06_小红书版`。
没有展示生图路径、模型、尺寸、输出路径和完整 prompt，停在 `06_小红书版`。

## 输入

- 本地 `06_小红书版` markdown
- 全局 `imagegen` 模型和凭证配置
- 用户明确确认

同一个 markdown 文件可能先包含小红书发布正文，再包含漫画分镜。忽略发布正文，只解析角色提示词和分镜提示词部分。

实际生图统一走全局 `imagegen` skill。本 skill 只维护小红书相关的 prompt 解析、执行顺序和本地输出规则。

## 输出

- `characters/role-a.*`
- `characters/role-b.*`
- `panels/panel-01.* ... panel-N.*`
- 生图请求和响应日志

## 执行顺序

1. 解析 `06_小红书版`
2. 提取角色提示词
3. 展示阶段级确认摘要
4. 每张角色图请求前展示完整 prompt 并等待确认
5. 生成 2 张角色图
6. 每张分镜图请求前展示完整 prompt 并等待确认
7. 生成分镜图
8. 把产物保存在本地文章输出目录供审看

## 失败规则

- 角色图失败：立即停止
- 单张分镜图失败：可继续后续分镜，并报告失败分镜编号
- 解析失败：停止并说明缺失的章节

## 重跑模式

- rerun-all
- rerun-panel

如果角色图变化，依赖它的分镜图必须全部重跑。

## 本地目录

推荐输出根目录：

`workspace/output/<article-slug>/xiaohongshu-images/`

子目录：

- `characters/`
- `panels/`
- `logs/`

## 审看规则

在本地输出目录审看图片。
