# 作者声音画像（模板）

这份文件把代表作和稳定的人审反馈编译成可执行的作者声音。公开版不附带任何真实作者画像；请用 `style-examples/` 中你有权使用的样文完成校准。

## 使用原则

1. **语料高于形容词**：样文里反复出现的写法，比“真诚、犀利、有网感”更可信。
2. **稳定偏好高于单次修改**：至少两次独立证据再升级为长期规则。
3. **内容正确高于风格相似**：不得为了语气牺牲事实、来源、逻辑和适用边界。
4. **先保护已成立部分**：风格深化不以改动幅度为质量指标，允许少改或不改。

## 平台边界

- 正文创作规则与公众号上传排版分开维护。
- 红字、小标题、互动尾注和图片位置属于平台表达，不自动升级为作者底盘风格。

## 更新规则

收到人工反馈时，先按 `docs/operations/feedback-loop.md` 分类：

- 能证明稳定作者偏好的，更新本文件；
- 依赖具体上下文或证据还不够的，写入 `content-feedback-library.md`；
- 只影响平台呈现的，更新对应发布标准或 skill；
- 单次偏好且无法复用的，只修改当前稿。

每条新规则都要保留来源、适用范围、反例和置信度。新证据与旧规则冲突时，改写或删除旧规则，不要只在文件末尾继续追加。
