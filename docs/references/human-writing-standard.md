# 活人感写作标准

## 目的

把“活人感”落实为可执行的写作机制，而不是口头禅、粗口、错别字、网络梗或密集金句。

本项目的活人感按以下顺序产生：

1. 有足够且可追溯的材料
2. 有明确的说话位置和判断边界
3. 段落持续带来新东西
4. 中文词序、停顿和段落有自然高低差
5. 最后才检查形式规则和常见 AI 痕迹

作者声音仍以 `docs/references/style-profile.md` 和用户提供的代表作样文为最高权重来源。本标准负责让文章“像一个具体的人在处理一件具体的事”，不另造一套作者风格。

## 上游来源与项目化边界

本标准借鉴 [human-writing 1.0.0](https://github.com/KKKKhazix/human-writing) 的材料门槛、说话位置、段落推进和改稿分层，核对版本为提交 `22d20b672680e4c1a34e75aec550ff48d622ca59`，上游采用 MIT License。

项目只吸收适合当前非虚构内容流程的机制，不整包复制通用 Skill：

- 不引入虚构写作分支
- 不覆盖作者声音和代表作样文
- 不把上游全部禁词升级为本项目硬规则
- 不把详细审稿清单塞进写作引擎的创作提示词
- 不用机械指标替代人工判断

## 起稿前的材料门槛

目标为一千二百字以上的公众号长文时，起稿前在内部列出至少五件具体材料，并记录来源。五件材料必须能组成一条真实过程、关系或冲突，不能只是五句相邻观点。

可计入的材料包括：

- 已核验的事实、时间、数字和价格
- 当事人或可靠来源中的原话
- 产品、组织或人物实际做过的动作
- 一次失败、限制、代价或后果
- 彼此冲突的材料和仍然未知的部分
- 用户明确提供的经历和判断

比喻、抽象后果、同义改写、模型临时想出的“典型场景”和没有来源的常识推演，不算新材料。

材料不足时按顺序处理：

1. 有公开资料可查，退回研究节点补材料
2. 依赖用户私人经历，一次最多询问三个关键问题
3. 用户不补充或题目确实材料稀薄，缩小主题或缩短篇幅

不要先交一篇空长稿，再等用户把活人感补进去。

## 材料身份

研究和起稿时，在内部区分：

1. 可靠来源可以直接证明的事实
2. 公司、机构或当事人的自述
3. 第三方回忆、媒体概括或社区讨论
4. 作者依据材料作出的推断与判断
5. 当前未知或存在冲突的部分

正文不需要展示整张核验表，但必须让重要事实的归属清楚。作者可以有判断，也可以承认拿不准，不能把推断写成事实，把查资料写成亲历。

## 找到说话位置

动笔前在内部回答：

- 谁在说，他凭什么知道
- 哪件事让他现在想说
- 哪条材料改变、加深或限制了他的判断
- 他最愿意承担的判断是什么，边界在哪里
- 读者读完上一段后最自然会追问什么

每篇只选择一两处知识来路自然进入正文，例如“我把几份发布说明对了一遍”“最初我也以为问题出在模型”。不要把五项全部凑齐，也不要靠反复写“我觉得”表演作者存在。

## 第一稿的正向罗盘

生成初稿、风格深化稿和平台改编稿时，使用下面三句罗盘，不加载完整审稿清单：

1. 从可追溯材料和明确说话位置出发
2. 每个新段落至少增加一项事实、动作、例子、区别、后果或诚实的不确定性
3. 先让主语和动作出现，再接时间、原因、条件与联想

补充原则：

- 后一段接住前一段留下的问题、动作或结果
- 背景知识只在它改变理解、风险或人物选择时出现
- 细节必须说明关系、代价、限制或变化，不能只负责布景
- 动作、原话或事实已经传出情绪时，少追一句解释
- 允许长短句、长短段落、补充和短暂岔话，但不能按固定节奏表演随意
- 普通地方用普通句子结束，关键短句才独立成段
- 外部连接必须由当前材料触发，出去一圈后带回新证据、新尺度或新理解
- 写到事情已经讲完就停，不在结尾重新摘要全文

引用具体研究时，首次出现至少交代机构或主要作者、准确时间和研究课题或标题。不要用“今年一项研究”“另一项实验”遮住已经可以查明的来源信息。无法核实核心署名信息时，降级为线索或删除。

`style-profile.md` 里的口语表达数量、关键短句和情绪标点属于成稿校验信号。不要在起稿时按配额插入口头禅或短句，它们不能代替材料、说话位置和推进。

## 内容类型路由

### 深度文

- 材料要能托住从现实摩擦到判断的过程
- 联想和语境扩展必须改变读者对当前事件的理解
- 判断可以偏、有情绪，但依据要在附近，边界要清楚
- 没有可靠现场时，从事实、原话、数字或直接判断进入

### 实用文

- 材料要覆盖任务、卡点、动作、可见结果、限制和成本
- 用普通角色走流程时，只能使用可核验的常见流程，不补伪造亲历
- 每个步骤写清动作与结果，原理讲到读者能处理常见变化即可
- 结尾回到核心动作，不临时追加宏大意义

## 初稿后的改稿顺序

详细审稿规则只在初稿存在后读取和执行。

1. **说话者**：作者凭什么知道，哪里真正在意，哪些段落换个模型也能原样写
2. **推进**：逐段标出新增内容，合并只换说法的段落，检查知识和联想是否回答眼前问题
3. **表演性中文**：清理假具体、假金句、假口语、抽象顺滑词和装饰性比喻
4. **中文节奏**：让主干早点出现，检查词序、照应、长短变化和单句段密度
5. **事实与硬规则**：核对事实身份、因果、引语、冒号、破折号和项目已有高敏感模式
6. **结尾**：分别删掉最后一段和最后两段试读，删掉更有力就提前结束

改稿先保护已经活着的地方。具体材料、独特判断、自然停顿和不完美但真实的说话关系，不应为了整齐、全面或“高级”被磨掉。

## 节点职责

| 节点 | 活人感职责 |
| --- | --- |
| 研究素材 | 形成可写材料清单，区分事实、自述、讨论、推断和未知 |
| 微信公众号初稿 | 执行材料门槛，确定说话位置，用三句罗盘完成第一稿 |
| 编辑修改 | 内嵌材料、来源、说话者、推进和 AI 痕迹检查，不单独生成模拟审稿文件 |
| 风格深化 | 把全部代表作作为同一语料库，按共同风格内核加深原稿，不把审稿清单前置 |
| 最终稿 | 内嵌发布前事实与表达校验，不无故新增主论点、事实或全文重写 |

## 交付判断

成稿至少应让审稿者回答清楚：

- 哪里让我相信作者确实知道这件事
- 哪条材料托住了核心判断
- 哪一段像人在处理问题，哪一段像模型在完成任务
- 每一段比上一段多带来了什么
- 文章在哪一句已经结束

回答不出来时，优先回到材料和说话位置，不继续增加修辞规则。
