# 小红书适配

## 先读

- `docs/operations/workflow-rules.md`
- `docs/references/content-type-standard.md`
- `docs/references/human-writing-standard.md`

## 核心职责

把公众号长文改写成适合小红书传播的双产物内容。不是翻译，也不是简单拆卡片，而是同时产出：

- 一份可直接发布的小红书标题和正文
- 一套连贯的漫画剧情分镜与生图提示词

如果上游已经经过公众号草稿箱人工校准，则默认输入不是原始 `05_最终稿`，而是 `wechat-publish-prep` 回读下来的 reviewed-source。

默认目标不是“短文案 + 配图说明”，而是：

- 有符合小红书社区风格、具备传播力的标题
- 有可直接发布的小红书正文
- 有稳定角色
- 有角色参考图提示词
- 有剧情推进
- 有对话解释
- 有每张漫画可直接用于生图的最终提示词

小红书的内容逻辑和公众号完全不同：

- 公众号：沉浸式阅读，叙事驱动
- 小红书：碎片化扫读，视觉+情绪+信息压缩驱动
- 漫画版小红书：用角色对话和连续分镜，把长文判断变成更易传播的理解过程

同时要读取上游的 `内容类型`：

- `深度文`：保留观点提炼、情绪识别、反差切口
- `实用文`：保留步骤、误区、清单感和“值得收藏后去试”的价值

---

## 默认输出

默认输出双产物小红书包。只有用户明确要求非漫画版本时，才例外处理。

分镜数量不固定，由原文密度和结构决定。

每次输出包含：

- 小红书标题
- 可发布正文
- 必要时给发布钩子或结尾互动句
- 推荐标签
- 漫画总设定
- 角色 A 设定
- 角色 B 设定
- 角色 A 参考图提示词
- 角色 B 参考图提示词
- 分镜列表
- 每张分镜的最终文生图提示词
- 改编说明

图片生成是下游独立阶段。本 skill 停在发布文案、分镜和 prompts，不直接生成图片。

## 来源优先级

来源按以下顺序使用：

1. 公众号草稿箱人工校准后回读的待发布源稿 markdown
2. 如果没有待发布源稿阶段，才使用原始 `05_最终稿`

始终把来源稿视为接近发布的公众号版本，小红书适配时需要重新提炼和重组。

先重新选择能托住短内容的事实、动作、原话、区别和后果。不要沿公众号原文逐段删字，也不要为了“更像小红书”补一个来源稿里不存在的职场对话、朋友故事或生活场景。

不要把公众号固定文章尾部当成故事内容。该尾部从 `>/ 作者：` 开始，包含三连、星标和评论引导，适配前要整体移除。

## 角色规则

写分镜前先定义两个固定角色，并在整组漫画里保持视觉一致。

### 角色 A

- 解释者或更有经验的一方
- 承担更锋利的判断
- 身份要自然贴合主题

### 角色 B

- 学习者或读者替身
- 提出读者可能有的明显疑问或不适
- 帮助把抽象判断拉回日常语言

### 必要角色设定

两个角色都要写清：

- 年龄
- 职业或社会角色
- 性格和说话方式
- 脸型
- 发型和发色
- 标志性视觉特征
- 服装和颜色
- 身高和体型，用数字描述
- 两个角色的关系

不要让角色外观在不同分镜里漂移。

定义两个角色后，分别输出一条专用参考图提示词。

这两条提示词是整组漫画的视觉锚点。生成后，后续分镜提示词直接引用 `角色A` 和 `角色B`，不要在每张图里重复完整外貌设定。

## 小红书漫画特征

### 格式元素

- 标题要激发好奇，但不能虚假
- 发布正文要像小红书原生内容，不像公众号切片
- 正文开头要尽快给出张力、洞察或情绪识别
- 漫画要像连续阅读体验，不是一组孤立卡片
- 每张分镜只承载一个清晰点
- 结尾要留下可评论或可分享的钩子
- 推荐标签保持垂直、具体

### 叙事结构

- 从具体不适、问题或小场景进入
- 让读者通过对话跟上解释
- 每张分镜只推进一个理解步骤
- 结尾把结论压回读者真实处境

### 语气

- 对话感
- 非专家也能读懂
- 友好但不幼稚
- 可以有轻情绪，但不要狗血

### 发布文案规则

- 标题和正文必须符合小红书社区阅读习惯
- 不要像公众号转载或 newsletter 摘要
- 正文要有明确开场钩子、核心判断、可转发的结论
- 可以保留观点密度，但必须压缩成更适合碎片化阅读的节奏
- 优先使用短段落、直接表达和来源稿中可追溯的现实材料
- 每个新段落都要增加事实、动作、例子、区别、后果或必要的不确定性，不用同义改写凑节奏
- 保留明确说话位置，读者要能感到这是有人在取舍材料和承担判断，不是匿名摘要
- 避免空泛鸡汤、标题党、过度夸张承诺

### 按内容类型适配

`深度文` 适配时：

- 优先提炼观点、反差、情绪识别点
- 允许更强的阅读牵引和余味

`实用文` 适配时：

- 优先提炼步骤、误区、前后对比、清单感
- 发布版要让用户一眼看出“我学会后能做什么”
- 漫画解释也要服务“立刻能试”的理解路径

## Prompt 标准

每张分镜都要输出完整最终生图提示词，不要只给简短画面说明。

每条 prompt 应包含：

- simple Chinese webcomic style
- clean black line art
- minimal pastel colors
- 直接引用角色A和角色B
- 场景描述
- 表情和肢体语言
- 中文对话气泡
- 必要时加入简单图标或图解元素
- 与上一镜的连续性
- 简单构图和镜头角度，保证一致性

角色参考图提示词确定后，不要在每条分镜 prompt 里重复完整角色外貌块。

prompt 要尽量能直接复制进生图模型。

## 写作执行

本节点默认由当前编排 Agent 完成实际小红书适配包写作。

当前编排 Agent 准备提示词，包含：

- 待发布源稿 markdown；如果没有待发布源稿，则使用原始最终稿
- 路线元数据
- `xiaohongshu-adapt` 输出格式和边界规则
- `human-writing-standard.md` 的三句正向罗盘
- 来源清理说明，尤其是固定公众号文章尾部的整体移除

如使用者显式配置外部写作引擎，模型、调用命令和失败处理只以 `docs/operations/workflow-rules.md` 的“可选外部写作引擎”为准。本 skill 不保存任何维护者专属命令或模型值。

写作执行生成小红书发布文案、漫画设定、角色设定、分镜和图片 prompts。当前编排 Agent 负责检查结构和规则，再保存本地产物并交接下游。

## 流程

1. **重新选材**：从来源稿选出能独立托住短内容的事实、动作、原话、区别和后果
2. **提取主线**：先判断原文最核心的一条主线，不要直接拆原文段落
   - 如果输入来自 reviewed-source，先整体去掉从 `>/ 作者：` 开始的固定公众号文章尾部和排版残留，再提取主线
3. **确认类型**：先确认上游是 `深度文` 还是 `实用文`
4. **确定说话位置**：明确发布版是谁在说、凭什么判断，不用“大家都知道”式匿名口吻
5. **先写发布版**：由当前 Agent 或已配置的外部写作引擎先输出适合小红书直接发布的标题和正文，而不是先拆漫画
6. **设计角色**：为这篇内容生成两个稳定角色，并写清视觉设定
7. **生成角色提示词**：分别输出角色A和角色B的参考图生成提示词
8. **拆分分镜**：按内容密度动态决定分镜数量，不固定张数
9. **重写对话**：把每个关键点改成自然对话，而不是讲义；角色不能只轮流复述结论
10. **保证连续**：每张分镜都要和上一张自然衔接，形成剧情推进
11. **生成最终提示词**：为每张分镜输出完整文生图提示词，直接引用“角色A / 角色B”
12. **补充标签**：给出适合小红书分发的标签

## 输出格式

本地产物保存为当前文章目录下的 `06_小红书版.md`。

The output should appear in this order so local artifacts and publishing stay aligned:

- `## 小红书发布版`
- `## 漫画总设定`
- `## 角色A设定`
- `## 角色B设定`
- `## 角色A参考图生成提示词`
- `## 角色B参考图生成提示词`
- `## 分镜列表`
- `## 推荐标签`
- `## 改编说明`

Inside `## 小红书发布版`, include:

- 小红书标题
- 小红书正文
- 发布节奏说明（如有必要，可 1 到 2 句）

Then continue with:

- 漫画总设定
- 角色A设定
- 角色B设定
- 角色A参考图生成提示词
- 角色B参考图生成提示词
- 分镜列表（动态张数）

For each panel:

- 分镜序号
- 本镜核心信息
- 画面描述
- 对话内容
- 与上一镜的衔接
- 最终文生图提示词

- 推荐标签
- 改编说明

## 边界规则

- 不要默认输出普通多卡片文案。
- 不要只输出漫画内容而缺少可发布标题和正文。
- 不要只输出模糊视觉方向。
- 不要提前固定分镜张数。
- 短文可能只需要少量分镜。
- 长文可以更多分镜，但不要让单张分镜过载。
- 默认交付物是发布文案 + 分镜 + prompts，不是最终生成图片。
- 如果需要实际图片，交接给独立的 `xiaohongshu-image-generation` 阶段。
- 角色提示词定义后，分镜 prompt 使用角色引用，不要重复完整外貌设定。
- 如果用户明确要求非漫画适配，按例外处理。
- 不要把固定公众号文章尾部（作者标识、三连、星标和评论引导）误认为文章正文内容。
