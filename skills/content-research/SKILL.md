# 研究素材

## 先读

- `docs/operations/workflow-rules.md`
- `docs/references/content-type-standard.md`
- `docs/references/human-writing-standard.md`
- 如果选题新鲜度敏感，也读 `docs/references/hotspot-collection-standard.md`

## 核心职责

围绕已确认的话题，收集、整理、归纳支撑素材，为后续写稿提供可引用、可展开、可核验的内容基础。

只做三件事：
1. 围绕话题收集素材
2. 整理成结构化研究摘要
3. 输出研究摘要，不直接写正文

---

## 输入

- 用户确认的话题或核心论点
- 完整写作流程中已有的 `00_选题卡.md`（如存在）
- 内容类型：`深度文` / `实用文`
- 或用户提供的一组散乱想法（需要先帮用户厘清话题方向）

如果存在 `00_选题卡.md`，直接继承其中的 route metadata、来源指针、待核验项和研究问题。不要要求重新打包或复制一份 handoff；研究完成后以 `01_研究素材.md` 取代选题卡作为下游事实来源。

---

## 研究规则

### 信息优先级

1. **搜索优先**：优先找一手来源和真实讨论
2. **原文优先**：能读原始页面就不读二手总结
3. **多方印证**：同主题至少覆盖 3 个不同角度或来源
4. **有判断，不搬运**：整理素材时带判断，不做搬运工

### 材料身份

按 `human-writing-standard.md` 在内部区分：

1. 可靠来源可以直接证明的事实
2. 公司、机构或当事人的自述
3. 第三方概括、回忆或社区讨论
4. 作者基于材料作出的推断
5. 当前未知或存在冲突的部分

不要把官方愿景写成已经发生，把社区猜测写成行业事实，或把作者推断混进来源原话。

### 写作托底

研究摘要要给下游提供可展开的具体材料，不只给观点分类。

目标为一千二百字以上的公众号长文时，至少整理五件可追溯的具体材料。它们要能组成一条真实过程、关系或冲突，并尽量覆盖动作、数字、原话、限制、代价、后果和未知中的不同类型。

如果材料不足，在研究 `Review Gate` 明确标出缺口和下一步补证方向，不要把抽象观点交给初稿节点灌成长文。

### 深度文的双线材料

深度文不能只收集“证明观点正确”的技术和行业材料。研究摘要至少同时建立两条材料线：

1. **事实与机制线**：技术怎样工作、组织怎样决策、谁承担后果、哪些数据和研究能证明。
2. **人文与情感线**：具体的人失去了什么、守住了什么、关系怎样变化，以及哪些历史、作品或文化材料能真正改变对当前事件的理解。

第二条线不是预先准备一段升华。每条外部连接都要写清它与当前事件共享的关系、困境或代价，以及它能为正文带回什么新解释。只有相似气氛、相似关键词或一句漂亮名言，不算有效材料。

### 具体研究的署名信息

凡是计划在正文中引用的实验、论文、调查或报告，研究摘要必须记录：

- 机构或主要作者
- 准确发布日期或实施时间
- 研究标题，或足以检索的课题名称
- 研究对象、样本或实验条件
- 它能证明什么、不能证明什么
- 原始来源链接

不要只记录“今年一项研究”“另一项实验发现”。如果无法确认上述核心信息，把它列为待核实线索，不交给正文充当权威背书。

### 时效规则

- 对 **AI / 招聘 / 产品更新 / 平台规则 / 职场变化** 这类高变化话题，默认优先使用**最近 30 天**材料。
- 如果最近 30 天内一手材料不足，再扩展到**最近 90 天**。
- 超过 90 天的材料只能作为**背景信息**，不能作为文章主判断的核心支撑。
- 研究摘要里必须明确写出本次研究的**时间窗口**；如果用了超窗材料，必须标注它只是背景，不是主证据。
- 用户明确要求“最新”“最近”“当下”时，按该要求优先，不得用旧材料偷换。

涉及登录态或动态网页时，使用环境提供的 `web-access` 能力。

### 研究范围

- 核心话题数据与事实
- 权威观点 / 经典著作引用
- 公司 / 产品 / 人物案例
- 平台真实讨论样本（支持与反对）
- 历史类比（适用时）

### 按内容类型调整重点

`深度文` 优先补强：

- 真实讨论和情绪样本
- 现象背后的结构原因
- 能支撑判断的案例
- 能把技术或行业事实重新放回人的尊严、关系、欲望、孤独和选择中的材料
- 有明确解释作用的历史、文化、作品或技术史连接

`实用文` 优先补强：

- 适用人群与使用边界
- 使用门槛、成本、替代方案
- 真实工作场景
- 常见误区和失败点
- 普通人可立即尝试的最小路径

### 搜索策略

- 先广撒网：不同关键词组合搜，了解话题全貌
- 再深挖掘：对最有价值的线索追溯原文
- 最后归纳：从多个素材中找出共同规律和分歧点

---

## 避免

- 不把搜索结果摘要直接当研究结论
- 不只依赖单一来源
- 不在研究阶段写判断性强的评论
- 不堆砌无来源的数据

---

## 输出格式

**研究摘要**包含：
- route metadata（内容类型 / 目标受众 / 文章目标）
- 话题简述（1-2 句话）
- 核心发现（3-5 个关键点）
- 可写材料清单（具体材料、身份、来源、能支撑的段落作用）
- 深度文双线材料（事实与机制线 / 人文与情感线）
- 具体研究署名卡（机构或作者 / 时间 / 课题 / 边界 / 原始链接）
- 支撑素材（按类别整理，带来源）
- 争议与分歧（如果存在）
- 关键未知与事实边界
- 研究结论（可引用的判断）
- 来源列表

---

## 流程

1. **理解话题**：确认自己真正理解了话题的核心张力
2. **制定搜索策略**：列出需要覆盖的角度和关键词
3. **执行搜索**：分批搜索，每批有明确目标
4. **深度阅读**：对关键内容读原文
5. **归纳整理**：按结构整理研究摘要
6. **材料门槛**：检查具体材料是否足以托住目标篇幅，不足时标出缺口
7. **输出**：研究摘要 + 来源列表
