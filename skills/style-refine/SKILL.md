# 风格深化

## 先读

- `docs/operations/workflow-rules.md`
- `docs/references/content-type-standard.md`
- `docs/references/human-writing-standard.md`
- `docs/references/style-profile.md`
- `docs/references/style-examples/` 中用户提供的全部代表作

## 核心目标

把 `03_修改稿` 审视并深化成更贴合作者声音的稿件，同时保护原稿已经成立的结构、节奏、准确度和情感关系。

本节点每篇必做，必做的是风格审视、候选生成和前后比较，不是结构性重写。深化可以保留原稿、局部修改，也可以在有明确结构证据时重构。改动大小不是质量指标；没有净收益时，`04_风格深化.md` 可以完整保留 `03_修改稿.md`。

最重要的风格来源是真实代表作，而不是抽象形容词。把目录中的样文视为同一个作者语料库联合阅读，不按本篇题材临时挑一篇模仿，也不复写样文的专有表达。

## 输入

必选：

- route metadata
- `01_研究素材.md`
- `03_修改稿.md`
- `style-profile.md`
- 用户提供的代表作全文

可选：

- 用户在 `03_修改稿` Review Gate 的反馈
- 用户明确要求保留的段落或表达

如果作者画像仍是空模板或没有代表作，停止并请用户补充；不要根据一篇当前稿件凭空发明长期作者声音。

## 写作立场

给写作引擎足够空间，但先说明本次真正需要补足的风格缺口和必须保护的部分。

可以鼓励它：

- 找到能统领材料的入口，不按素材提供顺序点名拼接；
- 让事实、动作、例子、区别和后果持续推动文章；
- 在代表作确有证据时复现相似的叙述节奏和判断生成方式；
- 保留复杂情绪，不急着给出漂亮答案；
- 只使用能改变理解的比喻、联想或段落组织。

不要要求它：

- 必须与 `03_修改稿` 有明显差异；
- 必须重写开头、移动材料或增加金句；
- 用口头禅、粗口、典故或诗性结尾证明“更像作者”；
- 把样文里的具体题材、人物、比喻或标志性句子搬进当前稿。

## 类型路由

### 深度文

可以提高叙事密度、语境铺陈、解释跨度和情绪余味，但事实与判断之间仍要有可追溯关系。

### 实用文

可以让入口、转折、例子和结尾更有作者感，但不能牺牲行动路径、适用条件和可见结果。

## 最小边界

- 不编造原材料里没有的事实、人物、对话、数据或场景。
- 不偏离用户确认的主题和核心判断。
- 不直接复写代表作的独特表达。
- 不用空泛 AI 腔替代真实判断。
- 只执行 `style-profile.md` 当前明确生效的规则，不把模板占位符当要求。

## 深化幅度判断

调用写作引擎前，先以 `03_修改稿` 为基线记录：

- 文章的核心问题与论证骨架；
- 最值得保护的开头、转折、段落节奏和结尾；
- 尚未成立的风格能力，最多三项；
- 不能因风格处理而损失的事实精度、术语和限定条件。

再选择最小可行幅度：

1. **保留型**：结构、语气和情感已经成立，只处理明确瑕疵，允许原样保留。
2. **局部深化型**：只改有具体缺口的段落，其他部分不动。
3. **结构重构型**：仅在核心问题不清、材料顺序阻断理解或论证骨架失效时使用。

默认选择保留型或局部深化型。单纯“还可以更有文风”不构成重构理由。

## 写作执行

本节点默认由当前编排 Agent 完成实际风格深化。如使用者显式配置外部写作引擎，则按 `docs/operations/workflow-rules.md` 的“可选外部写作引擎”执行。

当前编排 Agent 准备提示词，包含：

- 来源稿与研究材料；
- 路线元数据、已确认主题和核心判断；
- 代表作全文，作为一个共同语料库；
- `style-profile.md` 当前生效的作者声音规则；
- 本次深化幅度、真实缺口和保护项；
- 本地产物目标。

交接提示词必须允许写作引擎判断某段无需修改。不要把详细审稿规则、AI 味检查、发布限制或安全清单堆进创作提示词；这些由当前编排 Agent 在节点后置验证中处理。

Prompt intent：

> 请把全部代表作视为同一种作者文风的共同语料，先把握其中反复出现的叙述运动、材料组织、句法节奏和判断生成方式，再审视当前文章。以修改稿和研究素材为事实来源，保护已经成立的结构、准确度和情感关系，只补足已明确指出的风格缺口。如果原稿已经成立，允许少改或不改，不要用改动幅度证明深化。

## 流程

1. 读取修改稿、研究材料、内容类型、作者画像、代表作和用户补充要求。
2. 建立基线，列出原稿骨架、保护项和最多三项真实风格缺口。
3. 选择保留型、局部深化型或结构重构型中的最小可行幅度。
4. 联合阅读全部代表作，用反复出现的共同机制校准作者画像。
5. 由当前 Agent 或已配置的外部写作引擎生成完整候选正文。
6. 前后比较：主题、事实、骨架、开头、段落呼吸、阅读舒适度、结尾和行动路径是否至少没有退步。
7. 检查候选是否补上预先指出的缺口，是否新增伪事实，是否只堆叠表面风格信号。
8. 只有候选稿存在可说明的净收益时才采纳；否则保留原稿。
9. 保存 `04_风格深化.md`，报告深化幅度、保护项、实际改动和比较结果，停在 `Review Gate`。
